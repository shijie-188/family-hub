多端同步

数据存在你自己的 GitHub 私有 Gist 里，手机和电脑填同一份配置就能自动同步。 断网时照常使用，联网后自动补齐；改动会在几秒内上传，打开页面和每分钟会自动检查云端更新。

获取路径：GitHub → 头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)，只勾选 gist，有效期随意。

配置串里含 token，请只通过自己可控的渠道（如微信发给自己）传递，别发到群里。

自动备份

每天首次打开时自动存一份，最多保留 7 份。恢复前会把当前数据也存一份，可以再退回。
